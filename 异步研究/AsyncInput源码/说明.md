# AsyncInput（异步输入）相关游戏源码合集

> 来源：`文件导出\ExportedProject\Assets\Scripts\Assembly-CSharp\`（AssetRipper 反编译工程）
> 说明：本文件夹收录游戏中与异步输入（AsyncInput）系统直接相关的全部源码文件，
> 按层次分目录存放。行号为当前副本实际行号。

## 目录结构

```
AsyncInput源码\
├─ 01_核心模块\        系统本体：事件查询、队列/掩码管理、时钟对齐工具
├─ 02_输入抽象层\       RDInput 输入框架中接入异步键盘的部分
├─ 03_游戏集成点\       调用异步输入的游戏逻辑（完整原文件）
├─ 04_插件与参考\       SkyHook 预编译插件 + 其 IL 反汇编参考
└─ 说明.md              本文件
```

## 一、01_核心模块

| 文件 | 关键位置 | 作用 |
|---|---|---|
| `AsyncInput.cs` | 全文（104 行） | 对外查询 API：`GetKey/GetKeyDown/GetKeyUp`，按 Held/Down/Up 选择 `keyMask/keyDownMask/keyUpMask`，`frameDependent` 参数切换帧相关掩码 |
| `AsyncInputManager.cs` | 全文（208 行） | 单例管理器：`keyQueue` 并发队列、`currFrameTick/offsetTick`、6 套按键掩码；L37 调试作弊码 `asyncinputdebug`；L118-133 `Setup`（注册 KeyUpdated、过滤鼠标键、DontDestroyOnLoad）；L135-175 `Update`（游戏/非游戏状态切换普通键盘与异步键盘、清键）；L177-195 `OnGUI` 调试面板；L197-207 `OnDisable` 恢复普通键盘 |
| `AsyncInputUtils.cs` | 全文（75 行） | L7-14 `GetSongPosition`（事件 tick → 歌曲时间）；L16-19 `GetAngle`（→行星角度）；L21-28 `AdjustAngle`（事件时刻重算角度）；L30-38 `WhileFloorNotChange`（地板收敛循环）；L40-61 `UpdateOffsetTime`（挂钟/音频双时钟偏移对齐，÷100 EMA） |
| `AsyncKeyCode.cs` | 全文（64 行） | `(ushort key, KeyLabel label)` 结构体；L46-53 相等规则：键码相同**或**语义标签相同（左右 Shift 互为替补） |
